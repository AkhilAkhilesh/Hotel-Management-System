# Hotel-Management-System
The Hotel Management System is a backend API project designed to manage the core operations of a hotel business. It covers the full lifecycle of hotel and user management from registering hotels and users, to searching, booking rooms, and maintaining hotel facilities. 

Functional Domains
1. Hotel Management

Register new hotels (Save Hotel)
Search hotels by name (GetHotelByName)
Discover top-rated hotels by facilities (HotelWithMostFacilities)
Maintain and update hotel amenities (UpdateHotelFacilities)
2. User Management

Onboard new guests/users into the system (Save User)
3. Booking Management

Enable room reservations (BookaRoom)
Track and retrieve booking history per guest (GetBookingByPerson)
